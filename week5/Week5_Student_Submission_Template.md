## 📦 Submission Checklist

กรุณาตรวจสอบก่อนส่งงาน:

**Format:**
- [ ] ไฟล์เป็น PDF
- [ ] ชื่อไฟล์: `StudentID_Week5_Labs.pdf` (เช่น `6501234_Week5_Labs.pdf`)
- [ ] Font อ่านง่าย (Arial, Calibri, หรือ TH Sarabun)
- [ ] Font size อย่างน้อย 11pt

**Content:**
- [ ] ข้อมูลนักศึกษาครบถ้วน
- [ ] ทุก Lab มีคำตอบ
- [ ] Screenshots ชัดเจน อ่านได้
- [ ] อธิบายครบทุกข้อ
- [ ] Overall Summary เขียนแล้ว

**Quality:**
- [ ] Screenshots ไม่เบลอ
- [ ] Text มองเห็นชัดเจน
- [ ] ไม่มี sensitive information (passwords, private IPs)
- [ ] การจัดหน้าเรียบร้อย

**Before Submit:**
- [ ] เช็คตัวสะกดทั้งหมด
- [ ] อ่านทั้งหมดอีกครั้ง
- [ ] ตรวจสอบว่าครบ 100 คะแนน
