## 🛠️ Setup Instructions

### For Lecture
1. **Create Presentation:**
   - เปิดไฟล์ .drawio ใน diagrams.net
   - Export เป็น PNG (200% zoom)
   - Insert เข้า PowerPoint/Google Slides
   - เพิ่มเนื้อหาจาก .md file

2. **Print Materials:**
   - Week5_Network_Security_Packet_Filtering.md → PDF
   - พิมพ์แจกหรืออัพโหลด LMS

### For Labs
1. **Prepare VMs:**
   - ติดตั้ง Ubuntu 20.04+ ทุกเครื่อง
   - Update packages
   - Create snapshot (backup)

2. **Install Required Tools:**
   ```bash
   sudo apt update
   sudo apt install -y net-tools nmap tcpdump nginx
   ```

3. **Print Handouts:**
   - Week5_Quick_Reference.md → PDF (1 per student)
   - Week5_Ubuntu_Labs.md → PDF (optional)

4. **Setup LMS:**
   - Upload Week5_Ubuntu_Labs.md
   - Upload Week5_Student_Submission_Template.md
   - Create submission link
   - Set deadline
